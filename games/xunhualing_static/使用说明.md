# 寻花令 - 使用说明

## 文件结构

```
xunhualing_static/
├── index.html              # 主页面（直接双击打开）
├── poetry_data.js          # 诗词数据（JS格式，原始文本数组）
├── poetry_fulltext.js      # 诗词全文（答案弹窗「显示全文」用）
├── poetry_filter_database.txt  # 诗词数据源（文本格式）
├── txt_to_js.py            # 数据转换脚本
└── README.md               # 说明文档
```

## 使用方法

### 1. 直接打开使用
直接双击 `index.html` 即可在浏览器中打开游戏，**不需要启动服务器**。

### 2. 修改诗词数据
如果你想修改或添加诗词：

1. 编辑 `poetry_filter_database.txt` 文件，每行一首诗词，格式为：
   ```
   标题\t诗句\t作者\t朝代\t行数\t字数格式
   ```

2. 运行转换脚本生成新的 JS 文件：
   ```bash
   python txt_to_js.py
   ```

3. 刷新浏览器页面即可

## 数据格式

### txt 文件格式（制表符分隔）
```
静夜思\t床前明月光，疑是地上霜。\t李白\t唐代\t2\t5,5
```

### JS 文件格式
```javascript
const POETRY_DATABASE = [
  "静夜思\t床前明月光，疑是地上霜。\t李白\t唐代\t2\t5,5",
  "静夜思\t举头望明月，低头思故乡。\t李白\t唐代\t2\t5,5",
  "小池\t泉眼无声惜细流，树阴照水爱晴柔。\t杨万里\t宋代\t2\t7,7"
];
```

**特点：**
- 保留原始格式，不做任何处理和筛选
- 筛选逻辑（5,5和7,7格式）在HTML的JS中执行
- 随机选择时边选边验证格式

## 注意事项

1. 目前只支持 **5,5 格式（五言诗，10字）** 和 **7,7 格式（七言诗，14字）**，其他格式会在运行时被自动过滤
2. 诗句中的标点符号会在猜谜时被自动去除
3. 数据集中的所有句子都会保留，包括其他格式的诗词

## 玩法小功能

- **显示全文**：答对或点「查看答案」后，结果卡片下方有「📜 显示全文」，可展开该篇全文（数据来自 `poetry_fulltext.js`），再点一次收起。自定义或已删除的篇目没有全文数据时，该按钮会自动隐藏。
- **提示指定字**：猜中字之后点菜单里的「💡 获取提示」，弹窗下方会列出已猜中的字。点「随机」= 只要包含任意一个猜中的字；点 1 个字 = 只找含这个字的；点多个字 = 必须同时包含所选全部字。「换一条」保持当前选择换一首。检索在全部数据里进行，答案本身不做特殊处理，所以抽到的可能正是本局答案（提示里也写明了「不一定是答案」）。
- **模糊匹配**：菜单里的「🔍 模糊匹配」打开搜索框，输入诗句、标题、作者或朝代即刻筛选（无需点确定），匹配部分会高亮；用空格分隔多个关键词表示「同时满足」（如 `李白 明月`）。结果最多展示 80 条。

## 浏览器兼容性

- Chrome/Edge/Firefox/Safari 等现代浏览器
- 支持移动端浏览器
- **不需要网络连接**（纯本地运行）

## 问题排查

### 页面空白或无法加载
- 确保 `poetry_data.js` 文件与 `index.html` 在同一目录
- 检查浏览器控制台（F12）查看错误信息

### 数据未更新
- 修改数据后需要**刷新浏览器页面**
- 如果修改了 txt 文件，需要重新运行 `python txt_to_js.py`

### 随机选择太慢
- 如果数据集中5,5和7,7格式的诗词较少，随机选择可能需要多次尝试
- 建议保持足够多的目标格式诗词以提高选择效率
